# Principles

**Design Principles**: Initialize managers/stores at module level and distribute them to components via props. useEffect is exclusively for external synchronization (DOM, browser APIs, subscriptions). Never use it for data fetching or derived state computation. Always include a cleanup function. useMemo and useCallback are prohibited.

**Core Principles**: Immutable manager classes (PanZoomManager, RenderStateManager, StepZoomManager) return a new instance on every state change. Never mutate manager state directly. MermaidStore orchestrates all managers and notifies React via useSyncExternalStore.

**Use CSS design tokens**: All CSS values must use design tokens from `frontend/packages/theme/`. Two-tier structure: `--primitive-*` (font, size, spacing, border-radius, z-index, animation) and `--semantic-*` (color, shadow, border, editor, component). `generated/tokens.css` must not be edited (auto-generated by Style Dictionary). Hard-coding colors, spacing, border-radius, shadows, or z-index is prohibited.

**CSS Grid only**: Flexbox is prohibited. Use CSS Grid for all layouts.

**Pattern matching with ts-pattern**: Use `match().with().exhaustive()` for branching on discriminated unions. `switch/case + default` that swallows unknown variants is prohibited.
